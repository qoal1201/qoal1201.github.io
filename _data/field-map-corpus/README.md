# 분야 지도 원자료 — 문헌 코퍼스와 분류 결과

프롤로그([`experiments/2026-06-29-prologue.qmd`](../../experiments/2026-06-29-prologue.qmd))의 분야 지도 절에 실린 편수·비중·차트가 이 파일들에서 나왔다. 2026-07-03 자동 문헌 조사가 생성했고 2026-07-27에 이 자리로 옮겼다.

내용은 공개 논문의 서지 정보(OpenAlex ID·제목·제1저자·연도·인용수·게재처·DOI)와 거기에 붙인 분류 라벨이다.

## 파일

| 파일 | 무엇 |
|---|---|
| `corpus_714_dedup_before.csv` | 714편. 중복 병합 **전**. 지역·측정 여부 분류 라벨 포함 |
| `corpus_649_dedup_after.csv` | 649편. 같은 코퍼스를 중복 병합한 **후**. 발행 표가 쓰는 쪽 |
| `region_final.json` | 논문별 최종 지역 판정 |
| `paper_regions_cite.json` | 인용 관계에서 뽑은 지역 후보(288편). 분류기에 사전 힌트로 들어갔다 |
| `docs_regions.json` | 분류기 입력 문서(제목·초록·사전 힌트) |
| `measure_axis.json` | 측정 축 분류 결과 |
| `terrain_report.md` | 조사가 생성한 보고서 원문 |

## 발행 수치와의 대조 (2026-07-27 재현 확인)

```
중복 제거 전 714 → 후 649        (병합 65편)
지역 B+E   전 46+124 = 170       ← 본문의 "170편"
           후 38+107 = 145       ← 표의 145편
B+E 170편 중 measures=yes_method = 100   ← "측정 100편"
기타       전 53 / 후 50          ← 최초 지도의 부록 53 vs 표 50 불일치도 같은 원인
```

본문의 170과 표의 145가 어긋나 보였던 것은 오류가 아니라 **중복 병합 전후를 섞어 쓴 것**이다.

## 한계 — 이 파일들로 확인할 수 없는 것

- **분류 프롬프트 원문이 저장되지 않았다.** "무엇을 측정으로 쳤는가"를 원문 문장으로 인용할 수 없다.
- **"초록 1,186편"의 근거가 없다.** 어떤 파일에도 레코드 수 1,186이 없고 `terrain_report.md`의 서술 한 줄에만 나온다. 계산 흔적도 없다.
- **`paper_regions_cite.json`을 만든 코드가 남아 있지 않다.** 앵커 논문 목록·인용 방향(forward/backward)·후보 개수 규칙을 알 수 없다.
- 인용수는 수집 당시 OpenAlex 기준이다. 개별 논문 인용수 표기에는 Semantic Scholar를 쓴다(레코드 분리로 OpenAlex가 크게 과소집계된다).

## 함정 — `litmap_*`과 헷갈리지 말 것

같은 714편에 분류가 두 벌 있다. `litmap_*`은 TF-IDF와 K-means로 만든 **7개 스레드**이고, 여기 있는 `terrain_*`은 LLM 분류와 인용 힌트로 만든 **6개 지역 + 기타**다. **발행된 지도는 6지역 쪽**이다. `litmap_corpus.csv`를 대조에 쓰면 숫자가 전부 어긋난다.
