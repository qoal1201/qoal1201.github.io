# 이 번들은 무엇인가

**이 레포가 반복해서 쓰는 개념이 사는 자리.** 파일 하나 = 개념 하나, 경로가 식별자,
frontmatter + 마크다운 본문. 형식은 Open Knowledge Format v0.2 이고 채택 근거는
[kaggle-team ADR 0024](https://github.com/qoal1201/kaggle-team/blob/main/docs/adr/0024-adopt-okf-for-knowledge.md)
가 갖는다 — 여기 복제하지 않는다.

예약 이름은 `index.md` 와 `log.md` 둘이고, 그 밖의 모든 `.md` 는 개념 문서다.
갈래는 폴더가 아니라 `type` 으로 가른다.

# 무엇이 여기 오나

이 레포에는 지식이 사는 자리가 이미 여럿이고, 이 번들은 그것들을 대체하지 않는다.

| 자리 | 무엇이 사나 | 여기로 오나 |
|---|---|---|
| `glossary.qmd` | 공개 발행 용어 사전 (93항목) | **미정** — 독자용 발행물이라 성격이 다르다 |
| `paper-reviews/` · `experiments/` | 독자를 향해 쓴 공부글 | 아니오 — 개념 하나가 아니라 글이다 |
| `_papers/notes/` | 논문 노트 (로컬 전용) | 아니오 — 이미 자기 스키마와 검사기가 있다 |
| `CLAUDE.md` | 항상 로드되는 운영 지시문 | 아니오 — 찾아가서 읽는 지식이 아니다 |
| 하네스 memory | 일하는 방식 | 아니오 — 세션이 자동으로 읽는 층이다 |

# 개념

아직 없다.

카드는 박선호와 합의된 것만 등록한다. 에이전트가 초록을 맞추려고 혼자 채우지 않는다 —
그 사고가 다른 레포 둘에서 실제로 났다(`실측 2026-08-20`). 그래서 이 번들에는
개수 하한이 없고, **비어 있는 상태가 초록인 것이 설계**다.

# 한계 — 초록이 무엇을 뜻하지 않나

★ **부재는 검사할 수 없다.** 검사는 여기 있는 파일의 **형식**을 보지, 여기 없는 개념을
못 본다. 초록은 *"적힌 것이 형식을 지킨다"* 는 뜻이다.

★ **그리고 이 레포에서는 사각이 한 겹 더 넓다 — 지식 뭉치 대부분이 `.gitignore` 안이다.**
`_papers/notes/` 67장 · 에이전트 기억 22장 · `CLAUDE.md` · 백로그 보관본이 전부
git 밖이라, 검사를 GitHub Actions 에 걸면 **체크아웃에 없어서 아무것도 못 본다.**
git 안에 있는 것은 공개 발행물뿐이고 그것은 이 번들의 대상이 아니다.

그 밖에 검사가 안 보는 것:

- **검사가 언제 도나.** 지금은 손으로 돌린다. 붙일 자리가 정해지지 않았다
- **내용이 참인가.** 레포 안 출처 경로가 실재하는지는 보지만 본문이 그것을 옳게 옮겼는지는 못 본다
- **레포 밖 출처.** `http` 로 시작하는 `resource` 는 실재를 확인하지 않는다
- **배우 이름이 참인가.** 에이전트가 `verified` 에 `human:` 을 적으면 등급은 올라간다
- **낡음.** `stale_after` 가 지나는 건 파손이 아니라 사실이라 빨개지지 않는다

검사 실물: `tests/check_knowledge_bundle.py` (`--selftest` 로 빨개지는지 확인).
판정 로직은 상류에서 가져온 `tests/okf_document.py` 가 갖는다.
