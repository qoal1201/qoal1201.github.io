# 무엇인가

`glossary.qmd` 는 **독자를 향한 공개 한국어 사전**이다. 배운 개념을 쉬운 설명 + 학계
정식어 병기로 담는다. 579줄, `####` 항목 **93개**.

이 레포에는 사전이 둘이고 대상이 다르다. 이쪽은 **발행물**이고, 내부 운영 어휘는
[`CONTEXT.md`](../governance/vocabulary.md)가 갖는다. 그쪽 말은 **여기 일부러 안 싣는다.**

# 항목 골격

```
#### 용어 (학계 정식어) {#앵커}

한 줄 정의 — 그 줄만 읽는 사람에게도 맞아야 한다.

설명 문단 하나 — 비유·직관에서 시작해 우리 맥락과 출처 링크로.
```

즉 **본문은 문단 두 개**다. 표는 쓰지 않는다. 넘치는 이야기는 공부글 본문 몫이다.

★ **첫 줄은 그 용어의 *일반* 정의여야 한다.** 우리가 만난 맥락을 정의 자리에 올리면
안 되고, 우리 쓰임은 "이 사이트에선" 을 붙여 구분한다. 앵커 점프로 **단독으로 읽히는
사전**이라 본문이 자립해야 하기 때문이다.

# ★ 앵커는 링크 계약이다

앵커는 꾸밈이 아니라 **밖에서 걸린 링크의 착지점**이다.

`실측 2026-08-23`: `glossary.qmd#…` 링크가 **49회 출현, 43줄**에 걸쳐 있다
(한 줄에 링크가 둘인 경우가 있어 출현과 줄 수가 다르다). 출처는
**`paper-reviews/*.qmd` 46회, `experiments/*.qmd` 3회**다. `index.qmd`·`foundations/`·
용어집 자신에서 오는 링크는 **없다** — 홈은 용어집을 링크하지 않고, navbar 항목만
앵커 없이 페이지를 가리킨다.

`site_lint.py` 의 `check_links` 가 그 링크들의 **대상 파일과 앵커 존재를 검사한다.**
그래서 규칙이 하나 나온다:

> **앵커는 불변이다. 섹션 간 이동은 자유롭다.**

항목을 다른 절로 옮기는 것은 안전하지만 앵커 문자열을 바꾸면 밖에서 온 링크가 죽는다.

# 기계가 무엇을 막고 무엇을 흘려보내나

| 위반 | 등급 |
|---|---|
| `####` 헤딩에 `{#앵커}` 가 없다 | **오류** — push 를 막는다 |
| 같은 파일 안에 앵커가 중복된다 | **오류** |
| 항목 본문이 문단 2개를 넘는다 | 경고 |
| 항목이 길다 | 판정 안 함 — 참고 출력만 |

구조적 충돌(없거나 겹치는 앵커)은 막고 **장황함은 안 막는다.** 이 비대칭이 의도다.

# 길이 문턱은 조정된 게 아니라 폐지됐다

★ 예전엔 글자수 상한이 있었다. 그것을 맞추려다 실제로 지워진 것들이 기록에 남아 있다 —
어떤 개념이 어디서 왔는지, 어떤 메커니즘이 왜 반대 방향인지, 흔한 오해에 대한 대비,
그리고 한 항목은 **종결어미가 잘려 나갔다.**

규칙이 지키려던 것(용어집은 사전이지 리뷰가 아니다)은 **'문단 2개' 골격이 직접
강제한다.** 그래서 길이는 이제 최장 항목 다섯 개를 찍어 **보여주기만** 하고 아무것도
판정하지 않는다.

길이를 셀 때도 마크다운 링크의 URL 은 빼고 **독자가 실제로 읽는 분량**만 센다.
원문 글자수를 세면 인용을 성실히 단 항목일수록 장황 판정을 받았기 때문이다.

# 섹션 배치가 곧 출처 표시

용어집은 두 층으로 나뉜다.

- **기초 개념** — 정의 한 줄이 특정 논문 없이도 성립하는 것. 통짜로 두고 주제 인접순
  배치한다
- **논문별 섹션** — 그 논문의 장치·표기·조작화. 섹션 제목이 그대로 출처 표시다.
  지금 다섯 논문이 자기 섹션을 갖는다

경계 기준이 그래서 명확하다. *"정의 한 줄이 그 논문 없이도 성립하나"* 로 갈린다.
