# 무엇이 아닌가

`_tools/stats/` 의 두 스크립트는 **테스트가 아니다.** assert 가 없고, 실패로 끝나는
경로가 없고, [푸시 게이트](../editorial-guards/push-gate.md)도 CI 도 이것들을 부르지
않는다. 돌리면 표를 찍고 끝난다.

그럼 왜 레포에 있나. **발행된 글이 편 논증을 독자가 직접 돌려볼 수 있게** 하려는
것이다. 리뷰 본문이 "이 비교 구조에서는 우연히도 유의한 결과가 나온다" 고 주장할 때,
그 주장을 문장으로 믿으라고 하는 대신 실행 가능한 형태로 같이 둔다.

의존성이 없다. 표준 라이브러리 `random` 과 `math` 만 쓰고 Welch 근사도 손으로 짜여
있다. 그래서 아무 환경에서나 돈다.

```bash
python3 _tools/stats/significance.py
python3 _tools/stats/effect_size.py
```

# 씨앗이 고정돼 있다

두 파일 다 import 시점에 `random.seed()` 를 박는다. **그래서 출력 수치가 재실행해도
같다** — 글에 인용된 숫자가 다음 실행에서 달라지면 인용할 수 없으므로, 씨앗 고정은
편의가 아니라 인용 가능성의 조건이다.

# `significance.py` — 진짜 차이가 0인데 몇 번 유의가 나오나

핵심 설정은 한 줄이다. **두 집단 사이에 진짜 차이가 0이다.** 같은 분포에서 두 번
뽑았을 뿐이다.

첫 실험은 그 상태로 1만 번 비교해 `p < 0.05` 가 몇 번 나오는지 센다 — 0.05 라는 값의
뜻을 그대로 보여준다.

★ 두 번째가 본론이다. 리뷰 대상 논문의 구조를 그대로 흉내 낸다 — **정체성 하나당
24번 비교**(지표 6 × 모델 4). 진짜 차이가 0인데도 24번 중 몇 번이나 "유의" 가
나오는지를 1,000 세트로 센다. **여기서 나오는 유의는 전부 구성상 거짓양성이다.**

# `effect_size.py` — p값이 답하지 못하는 것

같은 문제를 반대편에서 친다. 진짜 차이를 **티끌만큼(0.05)** 으로 고정해두고 표본을
100 → 100,000 까지 키우면서 "유의" 판정 비율을 본다. 대조군으로 진짜 차이가 정확히
0인 조건도 같이 돌린다.

보이는 것은 **유의 판정이 차이의 크기가 아니라 표본 크기를 따라간다**는 것이다.
그래서 "유의하다" 는 "차이가 크다" 를 뜻하지 않는다.

# 한계

- **assert 가 없으므로 회귀를 못 잡는다.** 누가 로직을 바꿔도 스크립트는 여전히
  숫자를 찍고 정상 종료한다. 이것들이 여전히 옳은지는 사람이 출력을 읽어야 안다
- **Welch 검정을 정규 근사로 계산한다.** 표본이 크다는 전제 위에서만 맞고,
  스크립트가 그 전제를 주석에 밝힌다
- 두 스크립트는 **한 편의 리뷰에 붙어 있다.** 다른 글의 통계 주장까지 덮지 않는다
