# Triage Labels

스킬은 트리아지 역할 다섯으로 말한다. 이 파일이 그 역할을 이 레포 트래커의 실제
라벨 문자열로 잇는다.

| mattpocock/skills 의 라벨 | 이 레포의 라벨 | 뜻 |
| ------------------------- | -------------- | --- |
| `needs-triage`            | `needs-triage`    | 관리자가 판단해야 하는 이슈 |
| `needs-info`              | `needs-info`      | 보고자의 추가 정보 대기 |
| `ready-for-agent`         | `ready-for-agent` | 명세가 다 서 있어 에이전트가 바로 할 수 있음 |
| `ready-for-human`         | `ready-for-human` | 사람이 해야 함 |
| `wontfix`                 | `wontfix`         | 안 함 |

스킬이 역할을 부르면(예: *"AFK 준비 라벨을 붙여라"*) 이 표의 오른쪽 문자열을 쓴다.

2026-08-20 기본값 그대로 채택. 3-repo 가 같은 어휘를 쓴다 — 오른쪽 칸을 바꾸면
그 정합이 깨지므로, 바꿀 땐 다른 레포의 같은 파일도 같이 본다.
