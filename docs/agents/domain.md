# Domain Docs

엔지니어링 스킬이 코드베이스를 탐색할 때 이 레포의 도메인 문서를 어떻게 읽어야 하나.

## 탐색 전에 읽을 것

- 레포 루트의 **`CONTEXT.md`**, 또는
- 루트에 **`CONTEXT-MAP.md`** 가 있으면 그것 — 컨텍스트마다 `CONTEXT.md` 하나를 가리킨다. 주제에 걸리는 것을 각각 읽는다
- **`docs/adr/`** — 지금 손대려는 영역에 걸리는 ADR 을 읽는다

이 파일들이 없으면 **조용히 넘어간다.** 없다고 알리지 말고, 미리 만들자고 제안하지도 마라.
`/domain-modeling` 스킬이 용어나 결정이 실제로 정해지는 시점에 늦게 만든다.

⚠ **실측 2026-08-22: `docs/adr/` 는 생겼고 `CONTEXT.md` 는 아직 없다.** 첫 ADR 을 쓰면서
폴더가 났다 — 빈 폴더를 미리 파지 않는다는 원칙은 그대로다. `CONTEXT.md` 도 같다:
만드는 시점은 **용어가 실제로 정해지는 순간**이고, 그건 **지나갈 수 있는 조건이지
영구 상태가 아니다.**

⚠ **`CONTEXT.md` 를 `glossary.qmd` 로 대신할 수 없다** — 그건 독자용 발행물이라 이 레포
내부 어휘를 **일부러** 안 싣는다(`실측`: 밑돌·가든·작업호·체크포인트·페르소나 검수·진실원
전부 `glossary.qmd` 0건, `CLAUDE.md` 에만 있음). 언제 어디에 만들지는
[ADR 0001](../adr/0001-no-separate-context-file.md) 이 갖는다 — 다시 열 조건 셋이 거기 있다.

## 배치 — 단일 컨텍스트

모노레포가 아니다(`package.json` · `pnpm-workspace.yaml` · `packages/` 전부 없음).
그래서 루트에 `CONTEXT.md` 하나 + `docs/adr/` 하나다.

```
/
├── CONTEXT.md          ← 아직 없음 (ADR 0001)
├── docs/adr/           ← 있음
├── knowledge/          ← OKF v0.2 개념 번들 (별개 물건, 아래 참조)
├── paper-reviews/ · experiments/ · foundations/ · glossary.qmd
└── _tools/ · tests/
```

## ★ `knowledge/` 와 `docs/adr/` 는 다른 물건이다

이 레포에는 지식이 사는 자리가 여럿이라 종착지를 헷갈리기 쉽다.

| 무엇 | 어디 | 왜 |
|---|---|---|
| 반복해서 쓰는 **개념·용어·절차** | `knowledge/` (OKF v0.2) | 파일 하나 = 개념 하나 |
| **되돌리기 어려운 결정** | `docs/adr/` | Context·Decision·Consequences·다시 열 조건 |
| 독자를 향해 쓴 **공부글** | `paper-reviews/` · `experiments/` · `foundations/` | 발행물이라 레포에 결정 기록을 안 남긴다 |
| 공개 **용어 사전** | `glossary.qmd` | 발행물 |
| 논문 노트 | `_papers/notes/` (로컬 전용) | 자기 스키마와 검사기가 따로 있다 |

⚠ 레포를 건너뛰는 결정은 여기 안 산다 — 뿌리 이슈(qoal1201/brain)가 갖는다.

## 용어집의 어휘를 쓴다

출력이 도메인 개념을 부를 때(이슈 제목·리팩터 제안·가설·테스트 이름) `CONTEXT.md` 가
정의한 용어를 쓴다. 용어집이 일부러 피하는 동의어로 흘러가지 않는다.

⚠ **이 레포는 그 위에 규칙이 하나 더 있다** — 공부글의 용어는 **학계 표준 용어**를 쓰고
비유로 새 이름을 만들지 않는다(루트 `CLAUDE.md` 「용어는 정식 용어로, 설명은 비유로」).
`glossary.qmd` 가 그 표준 어휘의 발행본이다.

필요한 개념이 아직 용어집에 없으면 그건 신호다 — 프로젝트가 안 쓰는 말을 지어내고 있거나
(다시 생각한다), 진짜 빈칸이거나(`/domain-modeling` 몫으로 적어둔다).

## ADR 충돌은 드러낸다

출력이 기존 ADR 과 어긋나면 조용히 덮지 말고 명시한다:

> _ADR-0007(event-sourced orders)과 어긋난다 — 그래도 다시 열 만한 이유는…_
